# MentorX AI 🚀

**MentorX AI – Pakistan's Personal Career Coach** is an AI-powered career guidance platform designed for students and fresh graduates.

## ✨ Features

- 🎯 Career assessment and personalized career recommendations
- 📊 Skill gap analysis
- 🗺️ Personalized learning roadmaps
- 📄 Resume ATS-style feedback
- 🎤 AI-powered mock interviews
- 📈 Career dashboard
- 🌐 English and Urdu support

## 🛠️ Tech Stack

- Python
- Streamlit
- Google Gemini API

## 🔐 API Key Security

Store your Gemini API key in a `.env` file. **Never commit your `.env` file or API keys to GitHub.**

## 🚀 Run Locally

1. Clone this repository.
2. Install the required dependencies.
3. Add your Gemini API key to `.env`.
4. Run the Streamlit application.

## 🎓 Project Goal

MentorX AI aims to make personalized, AI-powered career guidance more accessible to students and fresh graduates in Pakistan.
