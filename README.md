# MentorX AI — Pakistan's Personal Career Coach

MentorX AI is an AI-powered career guidance platform designed to help Pakistani students and fresh graduates move from **career confusion to career readiness**.

It brings career assessment, personalized recommendations, skill-gap analysis, learning roadmaps, resume feedback, mock interviews, and progress tracking into one platform.

## ✨ Key Features

- 🎯 Career assessment
- 🧭 Personalized career recommendations
- 📊 Skill-gap analysis
- 🗺️ Personalized learning roadmap
- 📄 ATS-style resume analysis
- 🎤 AI-powered mock interview
- 📈 Career readiness dashboard
- 📥 Career report generation

## 🛠️ Tech Stack

- Python
- Streamlit
- Google Gemini API
- SQLite / database layer
- HTML/CSS for UI customization

## 🧠 How It Works

1. User completes a career assessment.
2. MentorX AI analyzes interests, skills, education, strengths, and goals.
3. The system generates suitable career recommendations.
4. Users receive a skill-gap analysis and learning roadmap.
5. Users can analyze a resume and practice through an AI mock interview.
6. The dashboard brings the user's progress and career-readiness information together.

## 🎓 Project Focus

MentorX AI was developed as a practical AI/EdTech project focused on making personalized career guidance more accessible to students and fresh graduates in Pakistan.

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/Engineer-Sarah/MentorX-AI.git
cd MentorX-AI
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Configure the Gemini API

Create a `.env` file and add your API key using the variable expected by the application.

**Never commit API keys or your `.env` file to GitHub.**

### 4. Run the app

```bash
streamlit run app.py
```
